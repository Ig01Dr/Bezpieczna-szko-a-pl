# Code of Conduct

Projekt przyjmuje [Contributor Covenant v2.1](https://www.contributor-covenant.org/version/2/1/code_of_conduct/).

## Nasze zobowiązanie

Dążymy do otwartej, przyjaznej i bezpiecznej społeczności. Szanujemy różnorodność i doświadczenia wszystkich uczestników.

## Niedopuszczalne zachowania

- Mowa nienawiści, dyskryminacja, molestowanie.
- Trolling, obraźliwe komentarze, ataki osobiste.
- Publikowanie danych osobowych bez zgody.

## Zgłaszanie

Zgłoszenia: conduct@safeschool.example (placeholder). Wszystkie zgłoszenia są rozpatrywane poufnie.

## Egzekwowanie

Opiekunowie projektu mogą usuwać komentarze, odrzucać commity i banować użytkowników łamiących zasady.
